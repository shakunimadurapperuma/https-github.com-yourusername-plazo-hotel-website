# Plazo Hotel Website

## Project Description
This project is an interactive website designed for Plazo Hotel. 
The website provides information about the hotel, services, rooms, 
and contact details for customers.

## Features
- Responsive design
- Hotel information section
- Image gallery
- Contact form
- Modern user interface

## Technologies Used
- HTML
- CSS
- JavaScript
- Bootstrap

## How to Run
Download the project and open index.html in a web browser.
